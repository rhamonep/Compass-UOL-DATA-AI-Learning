# Resumo da Sprint

- Nesta sprint, o foco foi aprofundar o conhecimento na ferramenta de Business Intelligence da AWS, o **Amazon QuickSight**, voltada à criação de dashboards interativos, relatórios dinâmicos e visualizações analíticas.

- Foram realizados dois cursos complementares — um introdutório pelo **AWS Skill Builder** e outro mais abrangente pela **Udemy** — que possibilitaram desde a configuração inicial da ferramenta até a criação de análises avançadas, com uso de filtros, parâmetros e cálculos personalizados.

- A partir dos exercícios práticos, foi possível desenvolver dashboards conectados a diferentes fontes de dados, aplicar boas práticas de visualização e compreender como utilizar o QuickSight em cenários de negócio reais.

---

## Udemy – *Complete Introduction to Amazon QuickSight*

- Este curso apresentou uma abordagem completa e prática sobre o uso do Amazon QuickSight, com foco na criação de dashboards interativos e relatórios analíticos com visualização clara e eficiente.

- Foi aprofundado o processo de conexão com diferentes fontes de dados, incluindo Amazon S3 e arquivos locais, além da criação e personalização de múltiplas visualizações como gráficos, tabelas e mapas.

- Também foram estudados recursos avançados como uso de **parâmetros**, **filtros dinâmicos**, **campos calculados** e **navegação entre páginas** nos dashboards. O curso ainda reforçou boas práticas de design visual, organização lógica das análises e publicação segura dos painéis para diferentes públicos.

- A aplicação prática dos conceitos permitiu consolidar o uso da ferramenta em pipelines analíticos, com foco em performance, clareza e geração de valor a partir dos dados.

---

## AWS Skill Builder – *Amazon QuickSight: Getting Started*

- Este curso introdutório apresentou os primeiros passos para utilizar o Amazon QuickSight, destacando como criar análises simples e compreender a lógica de funcionamento da ferramenta.

- O conteúdo abordou a navegação pela interface, a importação de conjuntos de dados e a criação de visualizações básicas. Também foram exploradas funções iniciais de filtros, ordenação e organização de gráficos, além de práticas para explorar os dados de maneira eficiente.

- A introdução permitiu compreender como estruturar análises a partir de dados já disponíveis, preparando a base para avançar para funcionalidades mais completas da ferramenta em contextos reais de BI.

# Exercícios

## Lab Amazon QuickSight

- Neste laboratório, utilizamos o serviço **Amazon QuickSight** para criar uma análise interativa a partir de um conjunto de dados de amostra chamado *Web and Social Media Analytics*.  

- O processo iniciou com o upload do arquivo CSV para dentro do QuickSight, configurando-o como novo conjunto de dados. Após a confirmação das configurações de importação, os campos foram carregados e exibidos no painel *Fields list*.  

- O QuickSight, por meio do recurso **AutoGraph**, sugeriu automaticamente a criação de um gráfico de linhas para mostrar as inclusões na lista de correspondência por dia, que é a granularidade padrão de datas.  

- Em seguida, ajustamos o gráfico expandindo o painel *Field wells* e alterando a dimensão de tempo do eixo X, agregando os valores de **dia** para **mês**. Dessa forma, foi possível visualizar a evolução mensal das adições à lista de correspondência ao longo do tempo.
