# Resumo da Sprint

- Nesta sprint, os estudos foram voltados para reforçar o entendimento sobre modelagem de dados em ambientes analíticos, explorar recursos de inteligência artificial voltados para desenvolvimento na AWS e finalizar a última etapa do projeto do Data Lake com dados do TMDB.

- O principal foco teórico foi na modelagem dimensional, aprendendo a estruturar dados para análise com tabelas fato e dimensão. Também foi estudado o Amazon Q, ferramenta de IA generativa da AWS, aplicada ao suporte de desenvolvimento e operações. Por fim, o projeto prático foi finalizado com a construção da camada refined do Data Lake, onde os conceitos estudados foram aplicados na modelagem e organização dos dados para consumo analítico.

## Modelagem de Dados para Data Warehouse

- O curso teve como foco principal a modelagem dimensional, apresentando os conceitos centrais para estruturar dados em um Data Warehouse.

- Foram estudadas as tabelas fato e dimensão, os diferentes tipos de fatos, granularidade, uso de chaves substitutas e boas práticas para construção de modelos voltados à análise de dados.

- Também foram abordadas as diferenças entre os esquemas estrela e floco de neve, com orientações sobre quando utilizar cada abordagem.

- O conteúdo mostrou como aplicar esses conceitos na prática, com foco em facilitar consultas analíticas e garantir clareza e desempenho na organização dos dados.

## Amazon Q Developer for Programmers and DevOps (Udemy)

- O curso apresentou o Amazon Q, ferramenta de IA da AWS voltada para auxiliar desenvolvedores e profissionais de DevOps.

- Foram mostradas funcionalidades como geração de código, explicação de trechos complexos e automação de tarefas.

- O conteúdo foi focado no uso prático da ferramenta para apoiar o desenvolvimento e a operação de soluções na nuvem, com foco em produtividade e agilidade.
